# meowdoku_project
This project was developed as part of the Math Concepts for Developers course. Meowdoku is a logic-based puzzle game designed for entertainment and recreational purposes. It challenges players to apply logical thinking and problem-solving skills. The rules of the game are explained throughout this project.
# Meowdoku: A Mathematical and Computational Comparison of Constraint-Based Search Algorithms

This project investigates the computational efficiency of two constraint-based search strategies for solving Meowdoku puzzles: basic backtracking and backtracking with the Minimum Remaining Values (MRV) heuristic.

## Project Structure

- `meowdoku_part_1.ipynb`: Mathematical foundations, dataset, and validation.
- `meowdoku_part_2.ipynb`: Basic backtracking implementation and benchmarking.
- `meowdoku_part_3.ipynb`: MRV implementation, benchmarking, and comparison.
- `meowdoku_part_4.ipynb`: conclusion and references.
- `data/`: Puzzle matrices, screenshots, and benchmark results.
- `solver/`: Search algorithm implementations.
- `experiments/`: Benchmarking, validation, and comparison functions.
- `validator.py`: Functions for checking puzzle solutions.

## Requirements

Python 3, pandas, matplotlib, and Jupyter Notebook.

## Running the Project

Run the notebooks in order:

1. `meowdoku_part_1.ipynb`
2. `meowdoku_part_2.ipynb`
3. `meowdoku_part_3.ipynb`
4. `meowdoku_part_4.ipynb`

Run them from the project root directory so that the relative file paths work correctly.
